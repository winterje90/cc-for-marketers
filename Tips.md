## Getting Started

- **Open links with Cmd+Click.** If Claude Code outputs a URL in the terminal (like a localhost preview or a documentation link), hold **Cmd** (⌘) and click the link to open it in your browser. Regular clicking won't do anything — you need the Cmd key.

## Workflows

- **Name your terminal windows.** If you run multiple Claude Code sessions at once (e.g., one for copy, one for a landing page), right-click the terminal tab and choose "Rename" to give each one a clear label. It saves you from guessing which window is which when you're switching back and forth.

## Gotchas

- **Watch out for Preview Mode.** When you single-click a file in VS Code, it opens in *preview mode* — the tab title is in italics. If you single-click another file, it replaces the first one. This can be confusing when Claude Code is making changes across multiple files and you're trying to follow along. Double-click a file to open it as a permanent tab that stays put.
