# [CLAUDE.md](http://CLAUDE.md)

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A living resource for marketers learning Claude Code. Two main sections:

1. **Tips & Tricks** (`Tips.md`) — Categorized, practical tips collected from real usage across various projects. Updated incrementally as new things are discovered.
2. **Guided Course** (`Course/`) — A structured, beginner-friendly walkthrough to help marketers get comfortable with Claude Code for the first time.

## Content Guidelines

- Write for a marketing audience — assume no prior coding or CLI experience
- Keep tips concise and actionable
- Course content should build progressively, starting from the absolute basics
- Use real-world marketing examples wherever possible (campaign pages, copy, SEO, analytics, etc.)
